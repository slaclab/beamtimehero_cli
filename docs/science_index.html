Grouped by directory, then module, in pipeline order. “Used by” is computed from a call graph that follows indirect routes (tool → handler → spec_data → science), so a function with no listed tool is very likely genuinely unreached. Resolution is static, so a call assembled at runtime (getattr, a name built from a string) is the one thing it cannot follow.
